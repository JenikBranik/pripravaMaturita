# Transakce a transakční zpracování - princip ACID vlastností, jazyk SQL-TCL příkazy a jejich použití, úrovně izolace a bezpečnost

## Definice a účel jazyka TCL
- TCL (Transaction Control Language)
- Specializovaná podmnožina jazyka SQL
- Oproti DML příkazům, které manipulují fyzicky s daty, TCL jen řídí a kontrolují tyto změny
- Hlavním účelem ja zajistit aby databáze bezpečně přešla z jednoho konzistentního stavu do zcela nového konzistentího stavu
- Díky TCL můžeme databázi "říct", kdy má skupina operací považovat za uzavřený celek a co má delat, pokud během nich dojde k chybě

## Hlavní příkazy TCL a jejich mechaniky
- Skládá se ze 4 základních příkazů
  - START TRANSACTION (nebo BEGIN)
    - Započne novou transakci
    - Od tohoto momentu se všechny následující DML operace zapisují pouze do dočasné paměti (Buffer) a nejsou viditelné pro ostatní uživatelé db.
  - COMMIT (Porvrzení)
    - Pokud všechny operace proběhly bez chyb, tento příkaz transakci úspěšně ukončí
    - Změny jsou potvrzeny a trvale zapsány na pevný disk
    - Ostatní uživatelé v tento moment uvidí nová data
  - ROLLBACK (Zrušení)
    - Záchraná brzda
    - Pokud aplikace narazí na chybu, příkaz `ROLLBACK` celou transakci okamžitě zruší
    - DB smaže dočasně buffer a vrátí do stavu, v jakém byla před zavoláním START TRANSACTION
  - SAVEPOINT (Záchranný bod)
    - Slouží pro řízení dlouhých a složitých transakcí
    - Umožňuje vytvořit uvnitř běžící transakce jakousi "záložku"
    - V případě dílčí chyby se nemusíme vracet (ROLLBACK) na úplný začátek a rušit celou práci, ale můžeme se vrátit jen k tomuto záchrannému bodu
    - Příkaz: `ROLLBACK TO SAVEPOINT nazev`

## Režim AUTOCOMMIT (Důležitý koncept z praxe)
- V souvislosti s TCL nezbytné zmínit AUTOCOMMIT, který je v DB nastavovatelný
- pr ORACLE. SET autocommit = {0|1}
  - Zapnutý AUTOCOMMIT (1):
    - Každý jednotlivý SQL příkaz (Např. každy UPDATE) se chová jako samostatná transakce
    - Systém si za něj automaticky doplní COMMIT
  - Vypnutý AUTOCOMMIT (0):
    - Vývojář musí běh řídit manuálně
    - Systém čeká, dokud výslovně nepošleme příkaz  COMMIT nebo ROLLBACK

## Syntaktické rozdíly mezi db systémy
- U řízení transakcí si každý výrobce vytvořil mírné odchylky v syntaxi
- MySQL:
  - Pro zahájení používá striktně `START TRANSACTION;`
  - Pro zachráněnné body používá `SAVEPOINT jmeno` a v případě návratu `ROLLBACK TO SAVEPOINT jmeno`
  - Nabízí příkaz `REALEASE SAVEPOINT jmeno`
- Oracle Database:
  - Velmi robustní, pro zahájení nabízí jak `START TRANSACTION`, tak tradičně BEGIN [WORK]
  - Příkaz `COMMIT` a `ROLLBACK` lze doplnit o klíčová slova WORK nebo param definující, zda má transakce po potrzené hned řetězit další
- Microsoft SQL Server (MSSQL)
  - Zásadně zahajuje transakce pomocí `BEGIN TRANSACTION;`
  - Podporuje pojmenování transakce pomocí proměnných např. BEGIN TRANSACTION @TranName, což je nesmírně užitečné pokud máme transakce zanořené do sebe
  - Pro stornování používá klasicky `ROLLBACk`
