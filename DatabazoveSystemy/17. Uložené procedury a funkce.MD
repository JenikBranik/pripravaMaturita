# Uložené procedury a funkce - syntaxe, procedura bez parametrů, s parametry vstupními/výstupními, úprava a spuštění procedury, příklad, typy systémových funkcí, uživatelská funkce - vytvoření a použití, rozdíl mezi procedurou a funkcí

## Uložené procedury
- Předkompilovaná sada SQL příkazů
- Je trvale uložená na straně databázového serveru
- Lze si ji představit jako db ekvivalent metod nebo funkcí z klasických prog. jazyků
- Hlavní vlasnosti
  - Mohou obsahovat libovolné množství příkazů skupin DDL, DML, DQL i TCL
  - Příkazy se uvnitř procedury provádějí sekvenčně
  - Zásadně snižují síťový provoz

## Typy procedur
- K procedurám můžeme definovat vstupní a výstupní params
- Procedura bez parametrů
  - Slouží k tvorbě statického úkonu
  - Příkaz: `CREATE PROCEDURE mp_osoby AS SELECT * FROM osoba;`
  - Spuštění: `EXEC mp_osoby`
- Procedura se vstupními param.
  - Uživatel při volání předa hodnotu, které se příkaz uvnitř zachová
  - Příkaz: `CREATE PROCEDURE mp_osoby_mesto @mesto varchar(20) AS SELECT * FROM osoba WHERE mesto @mesto;`
  - Spuštění `EXEC mp_osoby_mesto @mesto = 'Praha'` ## Pokud má procedura více params, odděluje se čárkou
- Procedura s výchozí hodnotou param
  - Pokud uživatel hodnotu nevyplní, proc nespadne, ale použije předdefinovanou hodnotu (např. Null)
  - Příkaz: `CREATE PROCEDURE mp_osoby_mesto @mesto varchar(20) = NULL AS ...`
- Procedure s výstupním param
  - Slouží k vrácení konkrétní hodnoty zpět do aplikace
  - Příkaz: `CREATE PROCEDURE mp_osoby_mesto @mesto varchar(20), @pocet int OUT SELECT @pocet = COUNT(*) FROM osoba WHERE mesto = @mesto;`
  - Spuštění: </br> `DECLARE @pocet_osob int;` </br>
              `EXEC mp_osoby_meto =  @mesto='Praha', @pocet = @pocet_osob OUTPUT;` </br>
              `SELECT @pocet_osob;` </br>
- Správa procedur
  - Změnu zajišťuje příkaz: `ALTER PROCEDURE jmeno_proc AS ...`
  - Smazání: Klasicky pomocí DDL příkazu `DROP PROCEDURE jmeno_proc;`

## Systémové funkce
- Na rozdíl od proc., databázové stroje v sobě obsahují stovky předpřipravených funkcí, které se dělí do kategorií
- Agregační funkce: Pracují s množinou dat(SUM(), AVG(), COUNT(), MAX())
- Textové funkce: Upravují text (UPPER())
- Matematické funkce: (ROUND() = Zaokrouhlení, ABS() = Absolutní hod.)
- Datumové a časové funkce: (GETDATE(), NOW() = aktuální čas, DATEDIFF() = rozdíl času)

## Uživatelsky definované funkce (USD - User Defined Functions)
- Pokud vývojáři nestačí sys. funkce, může si napsat flastní

```sql
-- Tvorba funkce pro výpočet DPH
CREATE FUNCTION funkce_dph (@CenaBezDPH Decimal(10,2))
RETURNS DECIMAL(10,2) -- Musíme striktně říct, jaký dat. typ funkce vrátí
AS
BEGIN
    RETURN @CenaBezDPH * 1.21;
END;

SELECT nazev, funkce_dph(Cena) AS Cena_celkem FROM produkt;
```
