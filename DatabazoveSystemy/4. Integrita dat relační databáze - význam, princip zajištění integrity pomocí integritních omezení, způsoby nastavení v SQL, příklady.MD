# Integrita dat relační databáze - význam, princip zajištění integrity pomocí integritních omezení, způsoby nastavení v SQL, příklady

---

## Význam integrity dat
- Integrita databáze znamená, že databáze je konzistentní, celistvá a data v ní uložená, jsou správně
- Abychom mohli db považovat za konzistentní, musí platit:
  - Neobsahuje redundantní (zbytečně se opakující) data
  - Neobsahuje datové sirotky, což jsou záznamy, které nikomu nepatří
    - př. - Objednávka na zakázníka, který už v databázi není
  - Každá infomace je uložená na jednom místě
  - Databáze musí striktně splňovat definovaná integritní omezení a pravidla
---
## Princip zajištění pomocí integritních omezení

#### Entitní integrita
- Pravidla: 
  - Každá entita musí mít jeden atribut, který je unikátní
  - Nesmí obsahovat prázdnou hodnotu (není null) 
  - Slouží k jednoznačnému vyhledávání
- **V praxi se jedná o primární klíč**

#### Referenční integrita
- Pravidla: 
  - Týká se entint s kardinalitou (vztah mezi tab.)
  - Kaýdá podřízená entita má jeden atribut, který odpovídá právě jednomu primárnímu klíči v nadřízené entitě
- V praxi:
  - Znamená, že každý cizí klíč v podřízené entitě musí přesně odpovídat nějakému existujícímu PK v nadřízené entitě, nebo může nabývat hodnotu NULL
  - Příklad:
    - Pokud má tabulka `žánr` jen ID '1,2,3' nemůžeš do tabulky vložit knihu s cizím klíčem 20
    - Db by takový krok zablokovala, přotože by tím vznikl sirotek

#### Doménová integrita
- Pravidlo:
  - Definuje přesné mantinely pro data v jednotlivých sloupcích
- Atributy entity jsou omezené např.
  - Použitím datovým typem (jmeno varchar, vek int, atd...)
  - Povoleným rozsahem (jmeno varchar(20))
  - Povinností nenulové hodnoty (NOT NULL)
  - Unikátnost (Unique)
  - Nebo nastavením defaultní hodnoty (Default) neboli hodnoty, která se nastaví, pokud není žádná jiná na vstupu

## Způsoby nastavení v SQL (Příklady)

```sql
-- Nadrazena tabulka
create table zanr(
-- Primarni klic je datoveho typu int, je nenulovy, pouziva funkci identity (auto_increment) a je to PK
id int not null identity(1,1) primary key,
nazev varchar(50) not null -- Nazev je dat. typu varchar a je nenulovy
);

-- Podrizena tabulka
create table knihy(
id int not null identity(1,1) primary key,
nazev varchar (30) not null,
pocet_stran int check(pocet_stran > 0), -- Ohlidani aby se daly zadat hodnoty pouze vetsi nez nula, pomoci metody check
skladem bit default 1, -- Defaultni nastaveni 1, pokud neni jinak zadano 1(True)/0(False)
zanr_id int not null, -- Vyvtovreni int atributu pro foreign key
foreign key (zanr_id) referenc[]()es zanr(id)  -- Definovani ciziho klice
); 
```

## Kaskádové akce
- **On Delete Restrict** (By Default)
  - Databáze smazání žánru zakáže (Nadřízeného prvku)
---
- **On Delete Cascade**
  - Databáze smaže žánr a automaticky smaže i všechny knihy, které pod něj patřily (Kaskádový efekt)
---
- **On Delete Set Null**
  - Databáze smaže žánr a u dotčených knih hodnotu cizího klíče na NULL
