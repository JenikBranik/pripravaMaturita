# SQL datové typy v různých databázových prostředích - popis a příklady použití

## Textové (Řetězcové) datové typy
- Jaký je rozdíl mezi pevnou a proměnlivou délkou?
  - Char(n):
    - Řetězec s proměnlivou délkou
    - ¨Pokud se definuje char(10) a vložíme slovo "Ahoj", db jej doplní 6 mezerami, aby zabralo přesně 10 bytů
    - Použití: Výhradně pro data, kde je délka vždy stejná
    - Velmi rychlé pro čtění
  - Varchar(n):
    - Řetězec s proměnlivou délkou
    - Pokud definujeme varchar(50) a vložíme "Ahoj", zabere na disku pouze 4 byty (plus malá režie pro zapsání délky)
    - O něco pomalejší na čtení
    - Použití: Jména, email atd...
  - Nvarchar(n) / NCHAR(n):
    - Písmeno N na začátku znamená National, neboli že sloupec plně podporuje kódování Unicode (Každý znak 2 byty)
    - Použití: Pokud přepisuji texty s českou diakritikou, azbukou, ...
  - Velké texty:
    - Dříve se používal typ TXT
    - Dneska již velmi zastaralý
    - V MSSQL se moderně používá Varchar(MAX), do kterého se vejde až 2gb textu

## Číselné datové typy
- Děli se do 2 rodin
  - Přesná čísla:
    - TINYINT = 1 byte, rozsah 0-255
    - SMALLINT = 2 byty, rozsah cca -32 tisíc az +32 tisíc
    - INT = 4 byty, rozsah -2 miliardy až +2 miliardy
    - BIGINT = 8 bytů
  - Přesná čísla s desetinou čárkou
    - DECIMAL(p, s) =
      - P = precision celkový počet číslic
      - S = scale, počet deset. míst
    - Použití: Peníže atd.. Kde máme definování deset. čárky a zaokrouhlování
  - Přibližná čísla
    - Float = Neukládají čísla naprost přesně
    - Použití: Např. peníze nikdy neukládáme do Float!!!!

## Datum a čas
- Standartní systém:
  - DATE = Pouze datum (RRRR-MM-DD)
  - TIME = Ukládá pouze čas
  - DATETIME = Ukládá obojí (RRRR-MM-DD HH:MM:SS)

## Logické speciální datové typy
- Ano/Ne = Jazyk v jádru pravý dat. typ boolean nemá
- Řešení:
  - MSSQL používá BIT pro 0, 1 nebo NULL
  - MySQL použivá TINYINT(1) (0=False,1=True)
  - PostgresSQL: Jako jeden z mála má plnohodnotný typ BOOLEAN (True/False)
- Moderní strukturové typy, normální podpora JSON, XML atd...
