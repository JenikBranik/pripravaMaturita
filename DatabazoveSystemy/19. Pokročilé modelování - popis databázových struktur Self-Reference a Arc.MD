# Pokročilé modelování - popis databázových struktur Self-Reference a Arc, význam, příklady využití, implementace v SQL

## Úvod do pokročilého modelování
- Většina reálného světa se dá popsat pomocí klasických vztahů 1:N neo M:N
- Někdy narazíme na situace, které jsou složitější: hiearchie, stromy nebo entity, které mohou patřit více různým majitelům
- Nesmí ale třeba platit současně atd.
- K vyřešení techto situací používají databázoví architekti struktury Self-Reference a Arc

## Self-Reference
- Nastává v situaci, kdy tabulka obsahuje cizí kláč, který má odkazovat na primární klíč téže tabulky
- Tato struktura se používá výhradně k modelování hierarchií a strom. struktur
- Např. Entity stejného typu mají mezi sebou vztah nadřazenosti a podřazenosti
- Příklady:
  - Organizační struktura firma: (tabulka `Zam`, každý zaměstnanec má svého šefa)
  - Kategorie e-shop (tabulka `Kategorie`, Notebook spadá pod Pc, Pc spadá pod eletro atd.)
  - Diskový systém (Složka na pc, která obsahuje složku uvnitř sebe)
- ```SQL
  CREATE TABLE Zam(
  id int not null identity(1,1) primary key,
  jmeno varchar(20),
  prijmeni varchar(20),
  id_nadrizeny int,
  foreign key (id_nadrizeny) references Zam(id)
  );
  ```
  
## Arc
- Používá když má jedna entita vztah několika k dalším entitám, ale z logiky věci může v jeden okamžik existovat vztah pouze k jedné z nich
- V ER diagramech se často kreslí jako oblouk, který protíná několik vztahových čar, aby ukázal: "Vyber si jednu cestu"
- Příklady z praxe:
  - Majitel bankovního účtu (Bankovní účet může vlastnist fyzická osoba nebo firma)
  - Info panel (Ticket může být přiřazen konkrétnímu zam nebo celé skupině)
  - Platba (Může proběhnout hotově nebo kartou)

```sql
CREATE TABLE bankovni_ucet(
    cislo_uctu varchar(20) PRIMARY KEY,
    zustatek DECIMAL(10,2),
                          
    id_osoba int null foreign key references FyzickaOsoba(id),
    id_firma int null foreign key references Firma(id),
    
    majitel_arc check (
        (id_osoba is not null and id_firma is null)
            or
        (id_osoba is null and id_firma is not null)
        )
);
```
