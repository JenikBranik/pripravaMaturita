# Vizualizace dat - princip a důvody, datové modely, tvorba vizualizací, hlavní funkcionalita a využití Power BI, import dat, příklady využití

## Vizualizace dat: Princip a důvody
- Vizualizace dat je proces převodu abstraktních, surových čísel a textů do grafické podoby
- Využívá faktů, že lidský mozek dokáže zpracovat vizuální vjemy mnohem rychleji a efektivněji než číst řádky v excelu
- Důvody proč:
  - Odhalení trendů a vzorů - Z tabulek o milionu řádků nepoznáme, že prodeje klesají každý měsíc
  - Identifikace anomálií - Graf okamžitě ukáže "odchylky", například výkyv ve výdajích
  - Data storytelling - Slouží k tomu, aby analytik dokázal složitá data jednoduše a srozumitelně odprezentovat managmentu
  - Zpřístupění dat netechnickým uživatelům - Ředitel firmy nemusí umět psát SQL dotazy, ovšem grafy mu postačí

## Tvorba vizualizací (Výběr správného grafu)
- Správný typ grafu dle toho, co chci ukázat
- Vývoj v čase = Používá se line nebo plošný graf (Vývoj tržeb za posledních 5 let)
- Porovnání kategorií = Používá se sloupcový graf
- Struktura celku = Používá se koláčový nebo prstencový graf
- Hledání korelace (Vztahů) = Používá se bodový graf (Scatter plot)
- Geografický data = Používají se kartogramy (Mapy)

## Datové modely
- Krásné grafy nemohou vzniknout bez kvalitního základu
- Tímto základem je dat. model
- Před samotvnou tvorbou grafů v Power BI se musí tab. navzájem propojit pomocí relací
- V praxi se nejčastěji používá Star Scheme - viz otázka 15.
- Jazyk **DAX** (Data Analysis Expressions):
  - Measures v modelu
  - Pomocí DAX analytik napíše vzorec, který se teprve následně vloží do grafu

## Power BI: Hlavní funkcionalita a architektura
- Lídrem v oblasti Business Intelligence
- Jeho architektura a práce v něm se skládá ze 3 hlavních technologických pilířů
  - **Power Query** = Nástroje pro ETL, zde se data extrahují, čistí a připravují pro model
  - **Power Pivot** = Zde se vytvářejí výše zmíněné relace mezi tab. a počítají se metriky v jazyce DAX
  - **Power View** = Grafické rohzraní, kam uživatel tahá vizuály a vytváří z nich interaktivní Dashboard
- Rozdíl mezi Power BI Desktop a Power BI Service
  - Desktop = Zde se report vytváří
  - Service = Cloud služba, kde se publikuje výsledek

## Import dat do Power BI
- Silné díky své vlastnosti napojit se na stovky různých zdrojů
- Umí se připojit na Excel, CSV 
- Relační DB
- Cloudové služby
- Při importu se analytik rozhoduje mezi dvěma režimy:
  - Import Mode: Data se fyzicky zkopírují a uloží přímo do paměti Power BI
    - Výhody: Extrémně rychlá odezva grafů
    - Nevýhody: Kapacitní omezení a nutnost data pravidelně aktualizovat
  - DirectQuery: Při každém kliknutí uživatele na graf se na pozadí vygeneruje SQL dotaz a pošle se přímo do zdroj. kódu
    - Výhody: Vhodné pro obrovská data a reportování v real. čase
    - Nevýhody: Výrazně pomalejší načítání grafů, protože závisíme na rychlosti zdrojového serveru

## Příklady využití v praxi
- Finanční controlling: Tvorba reportů, která sleduje Cash Flow
- HR (Lidské zdroje): Sledování fluktuace zaměstnanců
- E-commerce: Sledování návštěvnosti webu v reálném čase
- Výroba logistiky: Senzory na strojích IoT posílají data přímo do Power BI
